# Java Login Application

A simple Java Swing-based login application created for use in Eclipse.

## Features
- User Authentication UI
- Built with Java Swing (`JFrame`, `JPanel`, `JButton`, etc.)
- Clear/Login actions with basic credential validation

## How to run in Eclipse
1. Create a new Java Project in Eclipse.
2. Add `Login.java` to your `src` folder.
3. Run the file as a Java Application.
